# M5 — Workflow builder and smarter routing

## Files
- `src/workflow/` (React Flow, lazy), `workflow/model.ts` (templates + compile), `commands::workflow_*` (JSON in `.orchestrator/workflows/`)
- `db::outcome_stats`, `lib/insights.ts`, Telemetry → Routing insights

## Design
- The three modes ship as read-only templates; copies are editable and compile to a routing mode ("Use as mode").
- Router learning suggests reassignments from first-try pass rates per (class, tier, model); never auto-applies.

## Tests
- Vitest: template ↔ mode round trip, graph edits change the compiled mode, suggestion rules.
