# M1 — One paid, one open-source agent, end to end, in any folder

## Files
- `adapters/{mod,fake,fake_cli,cursor,opencode}.rs`, `providers/{mod,fake}.rs`, `proc.rs`
- `workspace/{mod,git,snapshot}.rs`, `handoff/{mod,plan}.rs`, `router/mod.rs` (Balanced), `governor/{mod,service}.rs`
- `engine/{mod,run,env}.rs`, `telemetry/{mod,sampler,cost}.rs`, `commands.rs`
- UI: `home/`, `runs/`, `statusbar/`, `components/Shell.tsx`

## Interfaces
- `AgentAdapter` (spec signature) + `CliSpec { bin, build, parse }` with a shared streaming runner.
- `StepRequest { workspace, task_file, prompt, model, library_agent, timeout, low_priority, api_key, cancel }`.
- UI events batched every 50 ms on `orch://events`.

## Tests
- Parser tests per adapter fixture; OpenCode fixture recorded against the fake provider.
- `tests/engine_run.rs`: full runs with the fake CLI (git + non-git, pool fallthrough, cancel, 10k-line flood).

## Budget impact
- No idle timers: sampler and UI bus sleep until there's work. Logs: 2,000-line ring + buffered file per step.
